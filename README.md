A one-page newspaper summing up the world news of Sunday 22 November 2026:
35 verified stories (3 illustrated leads, 8 illustrated secondaries, 24
numbered briefs), a UTC timeline, a region bar and a DATE CHECK box naming
the stories left out because they were first reported on 21, 20 or 19 November.

Leads: Iran strikes US assets in Bahrain (IRGC claims attack on two Patriot
radars); Mexico captures FBI's most-wanted El Chapo Isidro in Sinaloa;
Russian cargo ship Sparta II ablaze after a suspected drone strike off Finland.

`draw_news.py` draws the image with Pillow (all illustrations drawn in code,
no photographs); `main.py` copies `entry.png` to `/output/entry.png`.
Run `python3 draw_news.py` to re-render; two runs write identical bytes.

## Run it

```sh
python3 main.py
```
